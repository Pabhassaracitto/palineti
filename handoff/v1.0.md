1.1 Mô tả
PaliVip là ứng dụng Flutter học cổ ngữ Pāḷi theo phương pháp siêu trí nhớ
(Mind Game), tái sử dụng toàn bộ framework của VipLang. Nội dung dựa trên
giáo trình "An Elementary Pāḷi Course" của Nārada Mahāthera (26 bài học).

1.2 Nguyên tắc cốt lõi v8
  ✅ "Đủ dùng cho 26 bài. Ship được. Test được. Mở rộng được khi cần."
  ✅ Không over-engineering: ~260 từ, ~52 LessonDay — kiến trúc phải tương xứng
  ✅ Pure Dart paradigms — testable ngay, không cần mock
  ✅ Tái dùng tối đa VipLang framework — KHÔNG sửa file gốc

  Case  Singular    Plural
  Nom   -o          -ā
  Acc   -aṃ         -e
  Ins   -ena        -ehi / -ebhi
  Dat   -assa/-āya  -ānaṃ
  Abl   -ā/-asmā    -ehi / -ebhi
  Gen   -assa       -ānaṃ
  Loc   -e/-asmiṃ   -esu
  Voc   -a          -ā

6.1 Quy tắc MixedSegment — "Case-Hint Format"
  ✅ vietnamese = '[CASE_HINT] nghĩa tiếng Việt'
  ✅ answer = hình thái Pāḷi chính xác (có diacritics đầy đủ)
  ✅ english = đoạn Pāḷi thuần (không cần dịch) hoặc context

  CASE_HINT table:
  [CC số ít]    → Nom. sg.  | [CC số nhiều]   → Nom. pl.
  [ĐC số ít]    → Acc. sg.  | [ĐC số nhiều]   → Acc. pl.
  [SDC số ít]   → Ins. sg.  | [SDC số nhiều]  → Ins. pl.
  [CĐC số ít]   → Dat. sg.  | [CĐC số nhiều]  → Dat. pl.
  [XXC số ít]   → Abl. sg.  | [XXC số nhiều]  → Abl. pl.
  [STC số ít]   → Gen. sg.  | [STC số nhiều]  → Gen. pl.
  [ĐSC số ít]   → Loc. sg.  | [ĐSC số nhiều]  → Loc. pl.
  [HC]          → Voc. sg.  | [HC số nhiều]   → Voc. pl.
  [ĐT số ít]    → Verb sg.  | [ĐT số nhiều]   → Verb pl.

6.2 Cấu trúc Day 1 / Day 2 cho Pāḷi Lesson

  Day 1 — Học nền tảng:
  Phase 1: read_listen  → Giải thích ngữ pháp + bảng biến cách + từ vựng mới
  Phase 2: mind_game    → MixedSegments với Case-Hint Format

  Day 2 — Luyện tập dịch (từ Bài tập trong giáo trình):
  Phase 1: listening_quiz (Practice 1) → Câu 1-13 của bài tập
  Phase 2: mind_game                   → Ôn Practice 1
  Phase 3: listening_quiz (Practice 2) → Câu 14-27 của bài tập
  Phase 4: mind_game                   → Ôn Practice 2
  Phase 5: listening_quiz (Practice 3) → Câu 28-40 của bài tập
  Phase 6: mind_game                   → Ôn Practice 3

6.3 Quy tắc Quiz cho Pāḷi
  ✅ Câu hỏi tập trung vào: Nhận dạng case, Phân tích cú pháp, Dịch nghĩa
  ✅ Option sai phải plausible (sai case hoặc sai số)
  ✅ explanation trích dẫn quy tắc suffix làm bằng chứng
  ✅ 4 dạng câu hỏi xoay vòng:
     [A] Phân tích hình thái: "Buddhaṃ là hình thái gì?"
     [B] Dịch câu: "Narā gāmaṃ rakkhanti nghĩa là?"
     [C] Chọn hình thái đúng: "Chủ ngữ số ít của 'gāma' là?"
     [D] Điền vào chỗ trống: "Sūdo ___ pacati (cơm - ĐC số ít)"

6.4 Quy tắc Vocab Pāḷi
  ✅ Mỗi PaliVocabModel phải có: root, paradigmId, pronunciation
  ✅ pronunciation dùng Latin hóa đơn giản (không IPA phức tạp)
  ✅ examplePali là câu thực từ giáo trình gốc (ưu tiên)
  ✅ Verb: paradigmId = 'verb_conj1/2/..' (thêm sau Lesson 1)
